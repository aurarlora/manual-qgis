Sistemas de referencia y proyecciones en SIG

Para trabajar correctamente con información geográfica, es necesario definir cómo se ubican los datos en el espacio. Esto se logra mediante los sistemas de referencia espacial.

Un sistema de referencia espacial define dónde está un dato en la Tierra.

¿Qué es el EPSG?

El EPSG es un sistema de códigos que permite identificar de forma única los sistemas de referencia espacial utilizados en los SIG.

Estos códigos facilitan que diferentes usuarios y programas trabajen con la misma referencia espacial sin confusiones.

¿Sabías que el sistema EPSG surgió en la industria petrolera para estandarizar datos geográficos?

Hoy en día, el catálogo EPSG es mantenido por la IOGP y se utiliza a nivel mundial.

Puedes consultar estos códigos en:

  • https://epsg.org
  • https://epsg.io
