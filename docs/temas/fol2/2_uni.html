Unidad 2

Compatibilidad de proyecciones entre software SIG

Aunque ArcGIS y QGIS pueden mostrar nombres distintos para los sistemas de coordenadas, ambos utilizan la base de datos EPSG como referencia.

Esto significa que los datos pueden compartirse entre software sin perder su ubicación espacial.

Por ejemplo, un archivo exportado desde ArcGIS con extensión .prj puede ser leído sin problema en QGIS, y viceversa.

Ejemplos de equivalencia

Descripción EPSG Nombre en ESRI
WGS 84 (lat/lon) 4326 GCS_WGS_1984
UTM zona 14N (WGS84) 32614 WGS_1984_UTM_Zone_14N
NAD27 UTM zona 13N 26713 NAD_1927_UTM_Zone_13N
ITRF 2008 5332 ITRF_2008
El código EPSG es el idioma común entre los software SIG.
