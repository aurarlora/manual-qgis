Unidad 5

Introducción a los datos geoespaciales

Los datos geoespaciales son la base de cualquier proyecto SIG. Representan la información geográfica de nuestro entorno.

Existen tres tipos principales:

  • Datos vectoriales
  • Tablas asociadas
  • Datos raster (imágenes)
Todo proyecto SIG se construye a partir de estos tres tipos de datos.

Datos vectoriales (puntos, líneas y polígonos)

Los datos vectoriales representan entidades geográficas mediante:

  • Puntos
  • Líneas
  • Polígonos

Cada elemento puede tener atributos que describen sus características (nombre, tipo, valor, etc.).

Ejemplo: un pozo (punto), una carretera (línea), un área geológica (polígono).

Práctica del curso

En este curso trabajarás con datos reales organizados en la carpeta del proyecto:

  • Capas vectoriales en 1map
  • Imagen base en 3img (suelos.tiff)

Durante la práctica realizarás lo siguiente:

  1. Cargar capas del proyecto.
  2. Guardar el proyecto SIG.
  3. Crear polígonos a partir de una imagen base.
  4. Agregar un campo llamado Uso.
  5. Incorporar capas de líneas y puntos.
  6. Recortar capas utilizando límites geográficos.
Esta práctica integra los conceptos básicos del trabajo con datos vectoriales.
