Datos raster (imágenes)

Los datos raster son imágenes formadas por píxeles organizados en filas y columnas. Cada píxel tiene un valor que representa una característica del terreno o de la superficie.

Este tipo de datos se utiliza para representar información continua, como:

  • Modelos de elevación
  • Imágenes satelitales
  • Uso de suelo
Los raster representan superficies continuas mediante píxeles.

Práctica del curso

En esta sección realizarás dos ejercicios:

  1. Recortar la imagen de uso de suelo utilizando el límite del acuífero.
  2. Georreferenciar una carta topográfica de INEGI ubicada en la carpeta 3img.
Un raster puede ajustarse a una zona específica mediante recorte o alinearse correctamente mediante georreferenciación.

Herramientas

  • Cortar raster con una capa
  • Georreferenciar imagen
