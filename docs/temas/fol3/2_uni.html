Unidad 3

Recomendaciones clave para organizar tu SIG

  1. Rutas y nombres cortos.

    Ubica tu carpeta de trabajo directamente en la raíz del disco (por ejemplo, C:\proyectoSIG). Evita carpetas como “Documentos” o “Descargas”, ya que pueden generar rutas largas y problemas de portabilidad.

  2. Nombres sin espacios ni caracteres especiales.

    Evita usar espacios, acentos, símbolos o la letra “ñ”. Utiliza nombres simples con guiones bajos (_).

    Correcto: mb_altimetria.shp ✔
    Incorrecto: Mapa Altimetría.shp ✖

    Esto evita errores al usar herramientas o scripts dentro de QGIS.

  3. Ubicación del proyecto ejecutable.

    El archivo de proyecto de QGIS (.qgz) debe guardarse en un nivel superior al de los datos. Esto facilita su uso en otros equipos y su integración en procesos posteriores.

  4. Organización de la información.

    De acuerdo con la estructura anterior, cada carpeta puede contener la siguiente información. Si lo deseas, puedes crear subcarpetas para mantener un mayor orden; sin embargo, esto puede hacer más lento el acceso y la visualización de los datos.

    • 1map
      Capas vectoriales (.shp). Puedes usar prefijos para organizar: mb_altimetria.shp, id50.shp.
    • 2tab
      Tablas de datos (.xls, .csv, .dbf, .txt).
    • 3img
      Imágenes utilizadas en el SIG. Incluye solo las necesarias para el proyecto.
    • 4doc
      Documentos de apoyo (PDF, Word, fotos de campo, bibliografía).
    • 5tem
      Información temporal o en proceso de clasificación.
Mantener una estructura ordenada evita errores y facilita compartir el proyecto.
