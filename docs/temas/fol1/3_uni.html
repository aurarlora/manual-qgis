Introducción a los SIG

Roger F. Tomlinson es considerado el padre de los SIG por desarrollar, en la década de 1960, el primer sistema que permitió digitalizar, almacenar y analizar información geográfica a gran escala. Este sistema dio origen al Canada Land Inventory, una base de datos utilizada para la planificación del uso del suelo y la gestión ambiental.

Su enfoque integró geografía, estadística y computación, sentando las bases de una nueva disciplina: la ciencia de la información geográfica (GIScience).

Este avance marcó un cambio fundamental: se pasó de trabajar con mapas estáticos a utilizar mapas dinámicos, es decir, de observar a analizar.

SIG: herramienta que permite almacenar, organizar y analizar información geográfica.

Existen software SIG comerciales, como la familia ESRI, y opciones libres como QGIS, una de las herramientas más accesibles y utilizadas.

QGIS es un software libre y de código abierto que permite desarrollar proyectos de análisis espacial sin necesidad de adquirir licencias comerciales.

Su interfaz amigable y su capacidad para integrarse con múltiples fuentes de datos lo hacen útil tanto para tareas básicas como para análisis más complejos.

QGIS nació en 2002 como un proyecto comunitario, con el objetivo de crear una herramienta SIG libre que funcionara en diferentes sistemas operativos como Windows, Linux y macOS.

Desde entonces, su desarrollo ha sido continuo, impulsado por una comunidad activa de desarrolladores y usuarios en todo el mundo.
