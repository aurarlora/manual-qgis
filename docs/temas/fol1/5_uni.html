Inicio del programa QGIS

Al abrir QGIS, aparece una pantalla de inicio que muestra la versión del programa.

En este caso, la versión se llama “Münster”, en referencia a la ciudad alemana donde se realizó un encuentro internacional de usuarios y desarrolladores de QGIS.

¿Sabías que cada versión de QGIS lleva el nombre de una ciudad?

Cuando se abre QGIS por primera vez, lo más común es iniciar un proyecto nuevo.

Al crear un proyecto, aparece la etiqueta EPSG:4326 – WGS84. Esta indica el sistema de referencia espacial con el que trabajará el proyecto.

El sistema de referencia espacial define cómo se ubican los datos en el mundo.
Si ya conoces los sistemas de referencia espacial, puedes continuar con la siguiente sección. Si no, este tema es fundamental para trabajar correctamente con datos geográficos.
